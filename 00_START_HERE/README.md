# Start Here

Give the whole `ExtraBite-Antigravity` folder to Antigravity. If Antigravity accepts only one pasted instruction, paste `FINAL_CLEAR_PROMPT.md` in this folder.

The final clear prompt is self-contained and uses simple direct instructions. The remaining folders provide supporting details if Antigravity can read the full folder.

Build order:

1. Read `FINAL_CLEAR_PROMPT.md`.
2. Read the Customer App and Owner/Admin requirements.
3. Use the Product Data Spec while creating database, authentication, map, and QR features.
4. Do not call the app complete until every Acceptance Checklist item passes.

Non-negotiable: customers reserve in the app and pay the property owner directly at collection. There is no online payment feature.
